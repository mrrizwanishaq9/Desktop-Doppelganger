# 🖥️ Desktop Doppelganger V2030 Ultimate++

**Desktop Doppelganger V2030 Ultimate++** is an advanced Python + OpenCV real-time desktop visualization, recursive mirror, and visual FX studio designed for creative desktop experiments, screen visualization, recording, and performance monitoring.

The project captures your Windows desktop in real time and transforms it using multiple recursive and cinematic effects. It includes Infinite Mirror, Portal, Tunnel, Kaleidoscope, Spiral, Wave, Ripple, VHS, CRT, Glitch, Matrix, Thermal-style, Blueprint, Neon Edge, Chromatic, Fisheye, Pixelate, Ghost Echo, Invert, Edge Map, and Random FX modes.

## 🎥 Director Mode

Director Mode automatically changes visual effects according to a predefined sequence.

Example sequence:

Infinite Mirror → Portal → Tunnel → Kaleidoscope → Glitch → CRT → Matrix → Neon Edge

This makes it possible to create an automatically changing visual presentation without manually switching every effect.

## 🛡️ Safe Mode

Safe Mode is designed for lower-end systems.

When enabled, the application reduces processing intensity and uses a lower capture scale to help maintain a stable experience.
